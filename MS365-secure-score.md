# Microsoft Secure Score

## Overview

Microsoft Secure Score is a security measurement provided by Microsoft 365 that helps administrators evaluate and improve the organization's security posture.

Secure Score analyzes Microsoft 365 configurations and compares them against Microsoft's recommended security best practices. A higher score generally indicates that more security controls have been implemented. 


## Purpose

Secure Score helps administrators:

- Identify security gaps
- Review recommended security improvements
- Monitor security posture over time
- Track security progress
- Prioritize remediation efforts
- Compare against industry benchmarks

Open:

```text
https://security.microsoft.com/securescore
```

Or navigate through:

    └── Secure Score

## Common Recommendations

Examples of security improvements that may increase the Secure Score:

- Enable Multi-Factor Authentication (MFA)
- Protect privileged administrator accounts
- Configure Conditional Access policies
- Block legacy authentication
- Enable Microsoft Defender security features
- Improve data protection settings


---

## Review Frequency

Recommended review schedule:

```text
Monthly
```

Review new recommendations and address high-priority items where appropriate.

## Example

```text
Below 40%     Needs improvement
40% - 60%     Average
60% - 80%     Strong
80%+          Excellent
```
